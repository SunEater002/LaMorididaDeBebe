# La Mordida de Bebe

**La Mordida de Bebe** es una página web diseñada para ofrecer una experiencia única en la presentación de productos de boneless. La página incluye una interfaz atractiva y funcional, con secciones dedicadas a productos destacados, ofertas y contacto.

## Tecnologías utilizadas

- **HTML5**: Para la estructura del contenido.
- **CSS3**: Para el diseño y los efectos visuales, incluyendo animaciones y estilos responsivos.
- **JavaScript**: Para la funcionalidad interactiva, como el acordeón y el manejo de eventos.
